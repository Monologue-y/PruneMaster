# 关卡 JSON 格式规范 v1

所有关卡存放于 `game/assets/levels/level_XXX.json`（三位数字编号）。运行时由 `LevelData` 解析，并由 `LevelValidator` 强制校验——**校验不通过的关卡无法进入游戏**。

## 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | int | ✅ | 关卡编号，与文件名编号一致 |
| `name` | string | ❌ | 关卡名（展示用） |
| `lives` | int | ✅ | 生命值（默认 3） |
| `time_limit` | float | ❌ | 秒；缺省/负数 = 无限时（预留） |
| `trees` | Array | ❌ | 树元数据 `[{id, name}]`，供编辑器/着色使用 |
| `nodes` | Array | ✅ | 节点列表，见下 |

## 节点字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | int | ✅ | 全关唯一 |
| `pos` | [x, y] | ✅ | 设计分辨率 720×1280 坐标，原点左上 |
| `children` | Array[int] | ✅（可为空） | 子节点 id 列表（边 = 父 → 子） |
| `trees` | Array[int] | ❌ | 该节点所属的树 id；**多于 1 个 = 跨树共享节点**（橙色高亮） |
| `art` | string | ❌ | 美术变体 key（M3 使用，如 `bud_02`） |

## 校验规则（LevelValidator）

| 规则 | 等级 | 说明 |
|---|---|---|
| 节点数 ≥ 1，`lives` ≥ 1 | 错误 | |
| id 唯一 | 错误 | |
| children 引用存在 | 错误 | 悬空引用 |
| children 无重复、无自引用 | 错误 | 重复子引用会导致父节点永久不可剪（死局） |
| **图无环（Kahn 拓扑检测）** | 错误 | 环上节点永远不可剪，是唯一死局来源 |
| 任意两节点间距 ≥ 76px | 错误 | 防止视觉/点击重叠，并保证短枝仍能辨认粗细方向 |
| pos 位于安全区 x∈[40,680] y∈[140,1170] | 错误 | 避开顶部/底部 HUD |

## 布局建议（作者指南）

- 最终版将**节点位置与树结构解耦**：父子方向只由 `children` 决定，不能根据节点在屏幕上的上下位置推断。
- 生成器使用蜂窝点阵、随机旋转与轻微抖动；基础点阵间距为 81px，为 76px 校验阈值保留抖动余量。
- 手工关可以使用规则网格，但保存前必须由 `LevelValidator` 复核间距、边界和无环性；不要仅依赖“边向下”来保证无环。
- 共享节点通过 `trees` 中包含多个树 id 表达，位置可自由安排，以实际枝条辨识度为准。
